# Simple Python Number Guessing Game

Just another simple project I'm building to practice and improve my Python skills!

This is a basic command-line game where the computer picks a random number between 1 and 100, and you have to figure it out using hints. 

## Features
- **Higher/Lower Hints:** Tells you if your guess is too high or too low.
- **Guess Counter:** Keeps track of how many tries it took you to get it right.
- **Play Again Loop:** Easily start a new round without having to restart the script.
- **Crash Prevention:** Uses `try/except` blocks to handle invalid inputs (like typing letters instead of numbers) so the game doesn't break.
